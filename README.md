## 🧠 Sobre o CuidAI

### 💊 CuidAI — Inteligência Artificial aplicada à informação em saúde

Atualmente estou desenvolvendo o **CuidAI**, um protótipo que utiliza **agentes de Inteligência Artificial** para auxiliar na interpretação de prescrições médicas.

A proposta é utilizar IA para:

* 📄 Realizar a leitura de receitas médicas;
* 🔍 Fazer uma segunda verificação independente da leitura;
* 🗄️ Validar informações utilizando uma base de referência da **ANVISA**;
* 🔄 Transformar a prescrição em uma rotina organizada;
* ⚠️ Informar o usuário quando o sistema não possuir confiança suficiente na interpretação.

Atualmente, o projeto funciona como um **protótipo executado inteiramente em notebook**, com planos de evolução para implementações em **dispositivos móveis**.

> 🔬 Projeto em desenvolvimento — atualmente em fase de prototipação e testes.
